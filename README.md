# netflix-user-churn-prediction
# 🎬 Netflix User Churn Prediction

A Machine Learning project focused on predicting Netflix customer churn using user behavior and subscription activity data.

This project demonstrates a complete ML workflow including preprocessing, feature engineering, model training, evaluation, and hyperparameter tuning using Scikit-learn pipelines.

---

## 🚀 Models Used

* 🌲 Random Forest Classifier
* ⚡ Gradient Boosting Classifier
* 🧠 MLP Classifier

---

## 🛠️ Preprocessing & Techniques

The project uses:

* 🔄 `Pipeline`
* 🧩 `ColumnTransformer`
* 🔤 `OneHotEncoder`
* 📊 `StandardScaler`
* 🏷️ `OrdinalEncoder`
* 🎯 `GridSearchCV`

to efficiently handle categorical and numerical data.

---

## 📈 Goal

The main objective is to analyze customer behavior patterns and predict whether a user is likely to churn, helping streaming platforms improve retention strategies.

---

## 🧪 Evaluation

Models were evaluated using:

* ✅ F1 Macro Score
* 📉 Classification Metrics
